KILL YOURSELF ZUZANNA
1This app allows the user to connect with mental health services, book virtual therapy sessions, monitor mood, and get AI-designed and AI-crafted individual mental wellness plans. 
The app strives to give end-to-end mental wellness solutions by integrating proactive and reactive elements into the network so that the user can efficiently manage well-being.
##  Features

- **Mental Health Resources**  
  View categorized educational content (e.g., anxiety, depression, mindfulness)

- **Virtual Therapy Session Scheduling**  
  Schedule appointments with licensed therapists and receive reminders

- **Mood Tracker**  
  Input mood data daily and visualize patterns over time through trend graphs

- **AI Wellness Plans**  
  Get personalized, evolving mental wellness plans with actionable recommendations

- **Emergency Contact Management**  
  Save and update emergency contacts for quick access during crisis scenarios
